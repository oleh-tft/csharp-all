### Інструкція з встановлення
Після клонування репозиторію необхідно переіменувати файл `appsttings_sample.json`
до `appsettings.json`, 
- відкрити його властивості та встановити пункт **Copy to output directory** у значення **Copy always**
- відредагувати зміст файлу, замінити плейсхолдери *** на актуальні дані
